
# Sentiment Analysis for Mental Health

## Overview
This project performs sentiment analysis on mental health related text using NLP and Deep Learning techniques.

## Features
- Text preprocessing
- Tokenization
- BERT fine-tuning
- Emotion detection
- Sentiment classification

## Technologies Used
- Python
- PyTorch
- Transformers
- HuggingFace
- Scikit-learn
- Pandas
- NumPy

## Dataset
Mental Health Sentiment Dataset

- `finetuning_bert_on_emotion_detection.ipynb`
- `requirements.txt`
